# P'Wayz Happy Bins

Professional, SEO-focused static website for P'Wayz Happy Bins, an eco-friendly residential trash bin cleaning service in Arcola, Texas.

## Local preview

Run any static web server from the project root, for example:

```powershell
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Deployment

The site is configured for Netlify with `netlify.toml`. The publish directory is the repository root and no build command is required.

Form submissions appear in the Netlify dashboard under **Forms → service-request**.
